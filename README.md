# ConectaVidas

Sistema integrado de gestão social da Prefeitura do Recife — Kickoff Porto Digital 2026.

## Sobre o Projeto

ConectaVidas é uma plataforma mobile-first que conecta três eixos estratégicos:

- **Assistente Social** — Gestão de famílias vulneráveis, kanban de casos, encaminhamentos e alertas
- **Saúde** — Consultas, vacinação, visitas domiciliares e alertas clínicos  
- **Escolar** — Frequência, risco de evasão, perfil de alunos e encaminhamentos

## Tecnologias

- React 18 + TypeScript
- Tailwind CSS v4
- Vite 6

## Como executar

```bash
pnpm install
pnpm run dev
```
